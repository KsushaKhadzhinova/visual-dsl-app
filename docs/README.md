# Отчеты по дисциплине «ИТиВП»

Здесь лежат отчеты по дисциплине «Интернет-технологии и веб-программирование» (ИТиВП): практические занятия и лабораторные работы. Отчеты оформляются по стандарту предприятия БГУИР (СТП 01-2024) и по образцам выполненных лабораторных работ: титульный лист, содержание, введение, постановка задачи, теоретическая часть, ход работы, заключение и приложения с исходным кодом.

## Практическое занятие №1

Тема: «Middleware и шаблонизаторы» (Express.js и EJS), проект VisualDSL.

| Файл | Что это |
|---|---|
| `Отчет_ПЗ1.docx` | отчет по практическому занятию №1, исходный документ |
| `Отчет_ПЗ1.pdf` | тот же отчет в формате PDF |
| `Подготовка_к_защите_ПЗ1.md` | заметки к защите |
| `postman/`, `screenshots/`, `latex/` | коллекция запросов, снимки экранов и материалы для сборки |

## Лабораторные работы

Отчеты по лабораторным работам ИТиВП оформляются так же, как отчет по практическому занятию. Соответствие требованиям проверяется командой `report-gen lint` инструмента [report-gen](https://github.com/KsushaKhadzhinova/report-gen).
